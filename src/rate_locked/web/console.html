Details: what this is, where you are (guide), this run

Every number on these screens comes from this run. The world is the local FAKE of the Airwallex endpoints: nothing here calls Airwallex or any model.

  1. Three fictional supplier invoices arrive in three currencies. Code reads each field from its exact source words and sends anything doubtful to a person.
  2. Code, not a model, plans each payment: fund it from a balance, convert, defer, or escalate. A change in inputs recomputes only what it touches.
  3. Before any money moves, a person approves one exact set of terms (supplier, amounts, locked FX quote) on a separate approver page with the quote's clock.
  4. If the quote has expired, approving does nothing: zero conversion and zero payout calls. The agent asks for a new quote and shows what the new terms cost.
  5. After execution the record puts approved and executed terms side by side, and any exported copy can be checked offline.
